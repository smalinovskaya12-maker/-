# Рукописний набір (handwriting)

Відскановано з фото аркуша: 33 українські літери, 26 англійських, цифри 1–10, графічні знаки та маркери списку (усього 88).

- `svg/` — векторні контури (колір #1E2A8C), для Фігми
- `png/` — прозорі PNG у кольорі чорнила
- `glyphs.json` — координати кожного символу на оригінальному фото
- `overview.png` — оглядова таблиця

Назви файлів: `ua_а`, `en_a`, `num_1`, `sym_check`, `list_dash` тощо.
